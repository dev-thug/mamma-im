# 아기 돌봄 인수인계 체크리스트 검토 기록

- 검토일: 2026-10-01
- 글: `baby-care-handover-checklist`
- 범위: 생활용 인수인계 메모. 증상 판단, 응급 처치, 투약 처방 안내가 아님
- 참고 원문: [AAP / HealthyChildren.org, Babysitting Reminders](https://www.healthychildren.org/English/safety-prevention/at-home/Pages/Babysitting-Reminders.aspx)

## 독립 검토 1: 사실·출처·아동 안전

AAP 원문을 확인하고 출처가 뒷받침하는 연락처, 집 주소, 귀가 시간, 아이의 특이사항을 글의 자체 제안인 7칸 양식과 구분했다.

반영한 수정:

- 긴급 상황에서는 보호자의 답변을 기다리지 않고 지역 응급서비스에 먼저 도움을 요청하도록 표와 대화 예시를 일치시켰다.
- 투약 메모에는 약 이름, 의료진·약사에게 확인한 1회 용량·투여 방법, 예정 시각, 마지막 투여 시각을 적도록 했다. 지시가 불명확하면 임의로 투약하지 않는다.
- 합의한 음식·수유 방법·약만 따르도록 하고, 실제 개인정보가 담긴 메모는 돌봄 담당자에게만 공유하도록 했다.
- 미국의 연락번호·돌봄 담당자 연령 기준을 국내 독자에게 일반화하지 않았다.

수정 후 재검토 결과: 안전 관련 차단 사유 없음.

## 독립 검토 2: 편집·논리·검색 의도

기존 글 16개와 비교해 돌봄 인수인계라는 별도 검색 의도를 확인했다.

반영한 수정:

- 표와 함께 복사해서 채울 수 있는 일곱 줄의 빈칸 양식을 추가했다.
- 담당자가 자기 말로 확인할 일을 말하도록 대화의 화자 관계를 바로잡았다.
- 마지막 돌봄과 귀가 시간을 구체적으로 쓰고 가상 예시임을 표시했다.
- 존재하지 않는 전문가 경력, 가족 경험, 앱의 공유 기능을 주장하지 않았다.

수정 후 재검토 결과: 편집·논리 관련 차단 사유 없음.

## 배포 전 통합 검증

이미지 세 장은 승인된 원본 PNG에서 JPEG로 변환했으며, 글의 인수인계·준비물·귀가 후 확인 순서로 배치했다.

- 클라우드 환경 `npm run lint`: 통과. 오류 0개, 이번 변경과 무관한 기존 경고 6개.
- `npx tsc --noEmit`: 통과.
- `npm run build`: 통과. 새 글과 OG 이미지 경로를 포함해 정적 페이지 55개 생성.
- `git diff --check`: 통과.
- 기존 글 16개와 블로그 조회 함수가 변경되지 않았음을 비교 검증.
- 생성된 HTML의 canonical, OG/Twitter 메타데이터, 발행일, Article JSON-LD 검증.
- RSS 첫 항목 및 사이트맵 URL·수정일에 새 글이 반영됨을 검증.
- AAP 공식 원문 URL과 최종 수정일 확인. 출처 링크는 키보드 초점과 밑줄을 제공.
- JPEG 3개 모두 디코딩 성공, 1672×941, 각각 약 280 KB·231 KB·290 KB. 실제 이미지와 대체 텍스트 및 본문 순서 확인.
- 독립 통합 검토 결과: 차단 사유 없음.
- 로컬 서버의 HTML 응답은 확인했으나 클라우드 브라우저가 localhost 탐색을 `ERR_BLOCKED_BY_CLIENT`로 차단하여 배포 전 브라우저 레이아웃 검사는 수행하지 못함. 공개 배포 후 실제 페이지와 이미지 로드를 확인해야 함.
